# 요구사항
## 상품 상세
- 상품당 옵션을 추가
  - 상품당 옵션은 n개 있을 수 있다.
  - 상품 옵션에 대한 개념은 `ProductOption` 개념 클래스로 만든다
    - 상품(`Product`) 개념이 상품 옵션(`ProductOption`) 개념을 직접 알 필요는 없다
  - 상품 상세 API (findProduct) 에 옵션 정보를 추가한다.

## 리뷰 이미지
- 리뷰 작성 시 이미지를 첨부할 수 있다.
  - 이미지는 필수가 아니며, 최대 5개까지 등록 가능하다.
  - 이미지를 포함한 리뷰 작성 시 500원의 추가 포인트를 지급한다. (텍스트 리뷰 1,000원 / 이미지 리뷰 1,500원)
- 리뷰 목록 조회 시 이미지가 포함된 리뷰만 모아볼 수 있는 필터링 기능을 제공한다.
- 이미지 리뷰에 대한 제약 사항
  - 이미지 리뷰 수정 시, 모든 이미지를 삭제할 수 없다. (최소 1개 이상의 이미지가 유지되어야 함)
  - 이미지 리뷰는 삭제할 수 없다. (포인트 회수 로직 미구현에 따른 임시 정책)

## 찜하기
- 사용자는 Product, Brand, Seller를 찜할 수 있다.
- 찜 해놓은 Product, Brand, Seller의 변경사항이 있는 경우
